# 📚 StudySync – Your Personal Academic Productivity Hub

**StudySync** is a student productivity web application designed to help college students organize their academic lives, manage assignments, plan study sessions and track their productivity — all in one place.

It provides a centralized platform to manage everyday academic activities and build better study habits through an intuitive and interactive dashboard.

🔗 **Live Demo:** [Visit StudySync](https://study-sync-eosin-three.vercel.app/)

---

## ✨ Features

### 📊 1. Interactive Dashboard
- Personalized student dashboard.
- Overview of daily tasks and upcoming deadlines.
- Weekly study activity statistics.
- Academic progress visualization.
- Quick access to important features.

### 📅 2. Study Planner
- Create and manage study sessions.
- Organize sessions by subject and date.
- Daily and weekly schedule views.
- Track completed study sessions.

### 📝 3. Assignment Tracker
- Add, edit and delete assignments.
- Set deadlines and priority levels.
- Track assignment completion status.
- Filter and sort assignments.
- Identify overdue assignments.

### ⏱️ 4. Pomodoro Focus Timer
- 25-minute focus sessions.
- 5-minute short breaks.
- 15-minute long breaks.
- Start, pause and reset functionality.
- Track completed focus sessions.

### 📈 5. Subject Progress Tracker
- Add and manage academic subjects.
- Track study hours.
- Visualize subject-wise progress.
- Monitor academic productivity.

### ✅ 6. To-Do List
- Create and manage daily tasks.
- Set task priorities and deadlines.
- Mark tasks as completed.
- Filter pending and completed tasks.

### ⚙️ 7. Personalization
- Customizable student profile.
- Light and dark themes.
- Persistent data storage using browser localStorage.
